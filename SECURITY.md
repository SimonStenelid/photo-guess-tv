# Security policy

Security fixes target the latest release and the `main` branch.

Report suspected vulnerabilities through [GitHub's private vulnerability reporting](https://github.com/SimonStenelid/photo-guess-tv/security/advisories/new). Include the affected version, the conditions needed to reproduce the problem, and the potential impact. Remove host codes, real photos, and cloud credentials from examples. Give maintainers time to investigate and coordinate disclosure before publishing details.
